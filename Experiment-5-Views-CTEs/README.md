
# Experiment 5: Views, Employee Hierarchies, and Recursive CTEs

## Aim
To create database views and explore hierarchical queries using recursive common table expressions.

## Objectives
- Create views for employee information.
- Summarize salary information by department.
- Examine view updatability.
- Represent employee reporting relationships.

## Concepts Covered
- CREATE VIEW
- Aggregate views
- View updatability
- INFORMATION_SCHEMA.VIEWS
- Recursive CTEs
- Employee-manager relationships

## Files
- `experiment_5.sql` — view definitions and recursive queries.
- `Experiment-5-Views-CTE.pdf` — practical documentation.

## Prerequisite
Run Experiment 3 first. MySQL 8.0 or later is required for recursive CTEs.

## Outcome
Views and recursive queries are used to summarize data and explore reporting hierarchies.
