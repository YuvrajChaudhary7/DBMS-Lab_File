
# Experiment 6: Stored Procedures, Triggers, and Audit Logging

## Aim
To implement stored procedures and triggers for database validation, employee transfers, and audit logging.

## Objectives
- Transfer employees between departments using a stored procedure.
- Validate salary updates.
- Record salary changes in an audit table.
- Handle invalid employee and department identifiers.

## Concepts Covered
- Stored procedures
- Input parameters
- SIGNAL and error handling
- BEFORE UPDATE triggers
- AFTER UPDATE triggers
- Audit tables
- Data validation

## Files
- `experiment_6.sql` — stored procedure, trigger definitions, and test queries.
- `Experiment-6-Procedures-Triggers.pdf` — practical documentation.

## Prerequisite
Run Experiment 3 first. MySQL 8.0 or later is recommended.

## Outcome
Database procedures and triggers enforce validation rules and record salary changes.
