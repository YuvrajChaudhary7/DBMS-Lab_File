
# Experiment 1: ER Diagram for an Indian E-Commerce Platform

## Aim
To design an Entity-Relationship (ER) diagram for an Indian e-commerce platform and identify its entities, attributes, relationships, and constraints.

## Objectives
- Identify the main entities in an e-commerce system.
- Define primary keys and attributes.
- Represent relationships between entities.
- Understand weak entities and participation constraints.
- Represent specialization and multivalued or composite attributes.

## Entities
- Customer
- Product
- Order
- OrderItem
- Seller
- Category
- Payment
- Delivery
- Address

## Concepts Covered
- Entities and attributes
- Primary keys
- Relationships and cardinality
- Weak entities
- Composite and multivalued attributes
- Specialization and participation constraints

## Files
- `Experiment_1_ER_Diagram.pdf` — ER diagram and practical documentation.

## Outcome
The ER diagram represents the main entities and relationships required for an e-commerce database.
