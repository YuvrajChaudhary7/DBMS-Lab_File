
# Experiment 4: SQL Joins, Subqueries, Set Operations, and EXPLAIN

## Aim
To retrieve and analyze relational data using joins, subqueries, set-operation alternatives, and execution plans.

## Objectives
- Combine data from multiple tables.
- Compare employees within the same department.
- Use correlated subqueries and EXISTS.
- Examine query execution plans.

## Concepts Covered
- INNER JOIN
- LEFT JOIN
- Self-join
- Multi-table joins
- Correlated subqueries
- EXISTS and NOT EXISTS
- INTERSECT and EXCEPT alternatives
- EXPLAIN and EXPLAIN ANALYZE

## Files
- `experiment_4.sql` — SQL queries and execution-plan examples.
- `Experiment-4-Joins-Subqueries.pdf` — practical documentation.

## Prerequisite
Run Experiment 3 first to create the database and tables.

## Outcome
Complex queries are used to retrieve related data and inspect query execution plans.
