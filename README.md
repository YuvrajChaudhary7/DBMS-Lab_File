# DBMS Lab File

A collection of Database Management System (DBMS) laboratory experiments covering database design, SQL queries, normalization, transactions, and query optimization.

## 📌 About the Repository

This repository contains practical work completed as part of the DBMS laboratory course. It includes experiment documentation and supporting files for learning and practicing relational database concepts.

## 📚 Experiments Index

| No. | Experiment | Topics Covered |
|---|---|---|
| 1 | ER Diagram | Entities, attributes, relationships, keys, and constraints |
| 2 | Relational Schema | Table creation, primary keys, foreign keys, and integrity constraints |
| 3 | SQL Queries | Selection, projection, aggregate functions, grouping, and filtering |
| 4 | Joins and Subqueries | SQL joins, self-joins, correlated subqueries, and set operations |
| 5 | Views and CTEs | Views, recursive queries, and employee hierarchies |
| 6 | Procedures and Triggers | Stored procedures, validation, error handling, and audit logging |
| 7 | Database Normalization | UNF, 1NF, 2NF, 3NF, and BCNF |
| 8 | Transactions and Concurrency | Transaction management and concurrency control |
| 9 | Indexing and Performance | Railway booking database, indexes, and performance benchmarking |
| 10 | Query Optimization | Execution plans, slow queries, and performance improvement |

> **Note:** Experiments 7–10 are listed as part of the planned syllabus index. Add their files and update this note as you complete them.

## 🛠️ Technologies and Concepts

- **MySQL** — relational database management and SQL execution
- **SQL** — data definition, manipulation, retrieval, and constraints
- **Database Design** — ER diagrams and relational schemas
- **Performance Optimization** — indexing and execution-plan analysis

## 🎯 Learning Objectives

- Understand relational database design and implementation.
- Apply SQL commands to retrieve and manipulate data.
- Enforce data integrity using keys and constraints.
- Use joins, subqueries, views, procedures, and triggers.
- Understand normalization, transactions, indexing, and query optimization.
