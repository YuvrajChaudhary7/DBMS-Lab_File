# Experiment 7 – Database Normalization

## Aim
To study database normalization and convert an unnormalized database structure into normalized tables using 1NF, 2NF, 3NF, and BCNF.

## Description
Normalization is the process of organizing data in a database to reduce redundancy and prevent insertion, deletion, and update anomalies.

This experiment demonstrates normalization using a Student Course Enrollment database.

## Normal Forms Covered
- UNF – Unnormalized Form
- 1NF – First Normal Form
- 2NF – Second Normal Form
- 3NF – Third Normal Form
- BCNF – Boyce-Codd Normal Form

## Database Tables
- Student
- Department
- Course
- Instructor
- Enrollment

## Software Used
- MySQL
- MySQL Workbench

## How to Run
1. Open MySQL Workbench.
2. Open `experiment_7.sql`.
3. Execute the SQL statements.
4. View the normalized tables.
5. Execute the final JOIN query to view combined student, department, course, and instructor information.

## Output
Screenshots of table creation, normalized tables, and the final JOIN query are included in the experiment PDF.

## Result
The database was normalized to reduce data redundancy and improve data integrity using normalization techniques.
