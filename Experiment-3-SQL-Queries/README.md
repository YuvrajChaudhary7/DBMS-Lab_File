
# Experiment 3: SQL Queries Using Employee, Department, and Project Databases

## Aim
To perform SQL queries on an employee, department, and project database.

## Objectives
- Create relational tables and insert sample records.
- Retrieve records using conditions.
- Apply aggregate functions.
- Group and sort query results.

## Concepts Covered
- SELECT and WHERE
- Projection and selection
- COUNT, SUM, AVG, MIN, MAX
- GROUP BY and HAVING
- CASE expressions
- ORDER BY
- Table joins

## Files
- `experiment_3.sql` — SQL table definitions, sample data, and queries.
- `Experiment-3-Employee-Queries.pdf` — practical documentation.

## Prerequisite
MySQL database environment.

## Outcome
SQL queries are used to retrieve, filter, group, and summarize employee and project data.
