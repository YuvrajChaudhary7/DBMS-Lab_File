
# Experiment 2: ER-to-Relational Schema Mapping

## Aim
To convert an ER model into relational tables and implement the schema using MySQL.

## Objectives
- Map entities and relationships to relational tables.
- Define primary and foreign keys.
- Apply integrity constraints.
- Understand referential actions.

## Concepts Covered
- Relational schema design
- CREATE TABLE
- Primary and foreign keys
- NOT NULL and UNIQUE constraints
- ON DELETE CASCADE and SET NULL
- Referential integrity

## Files
- `Experiment_2_Relational_Schema_MySQL.pdf` — practical documentation and SQL examples.

## Outcome
A relational schema is designed and implemented with appropriate keys and integrity constraints.
